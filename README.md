# PokéPal HG — ROM Edition v7

This build keeps the ROM-extracted HeartGold sprites and room/battle assets, and adds:

- Bond meter that directly modifies battle damage
- Type effectiveness, STAB, accuracy, critical hits, smarter wild move selection, guarding and run chance
- Training Disc system: level up -> earn a disc -> return home -> watch the TV -> learn/replace a move
- Level-gated rare/dangerous wild Pokémon with sprites extracted from the supplied HeartGold dump
- A walk-in Poké Mart scene instead of a shop-only menu
- Buyable/equippable accessories with visible cosmetic overlays
- Soothe Bell and other accessories that affect bond gain
- Permanent battle death remains supported when Mortality Mode is enabled

Upload every file/folder in this package to the root of the GitHub Pages repository.
